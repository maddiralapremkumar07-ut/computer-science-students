
# Simple Calculator

## Description
A basic calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling

## Technology
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Run:

   python calculator.py
